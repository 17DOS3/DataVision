# 📊 DataVision – Data Analytics Platform

DataVision is an interactive data analytics platform built with Python and Streamlit.
It allows users to upload datasets, explore data, perform statistical analysis,
visualize information, clean datasets, and generate reports.

## 🌐 Live Demo

Try DataVision online:
[Open DataVision](https://datavision-ufmezbl8zywa62ym4sf99f.streamlit.app/)

## 💻 GitHub Repository

[View Source Code](https://github.com/17DOS3/DataVision)

## 🚀 Features

- 📁 CSV and Excel file upload
- 📊 Interactive dashboard
- 🔍 Data exploration
- 📈 Descriptive statistical analysis
- 📉 Interactive charts using Plotly
- 🧹 Data cleaning and duplicate removal
- 🚨 Data quality analysis and validation
- 📄 PDF report generation
- ⬇️ Download cleaned datasets and reports

## 🛠️ Technologies

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- ReportLab
- OpenPyXL
